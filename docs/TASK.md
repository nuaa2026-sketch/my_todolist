## 2. 단계별 작업

### Phase 1 — 기본 구조
- ✅ T1-1 `index.html` / `style.css` / `script.js` 3파일 구성
- ✅ T1-2 제목 "My Tasks", 입력창 + 추가 버튼, 목록 컨테이너
- ✅ T1-3 할 일 추가 (Enter·버튼 모두, `<form submit>`으로 통일)
- ✅ T1-4 X 버튼 삭제, 체크박스 완료 토글, 완료 시 취소선
- ✅ T1-5 localStorage 자동 저장·복원, `{ id, text, completed, createdAt }` 구조
- ✅ T1-6 카드 레이아웃(중앙 정렬, 최대 600px), 호버 효과·트랜지션
- ✅ T1-7 XSS 방지 (`textContent` 사용), 손상된 저장 데이터 처리

### Phase 2 — 카테고리
- ✅ T2-1 업무/개인/공부 카테고리 + 추가 시 드롭다운
- ✅ T2-2 카테고리 색상 태그·왼쪽 테두리 (#4A90E2 / #27AE60 / #8E44AD)
- ✅ T2-3 필터 버튼(전체/업무/개인/공부), 선택 강조, 필터 상태 저장
- ✅ T2-4 상대 생성 시간 표시("2시간 전"), 1분마다 갱신
- ✅ T2-5 완료 항목을 목록 아래로 자동 정렬
- ✅ T2-6 `category` 필드 추가, 이전 데이터 호환

### Phase 3 — 대시보드·인라인 수정
- ✅ T3-1 전체 진행률 "n/m 완료 (p%)" + 진행률 바
- ✅ T3-2 카테고리별 미니 진행률, 오늘 추가한 개수
- ✅ T3-3 더블클릭 인라인 수정 (Enter 저장 / Esc 취소, 카테고리 변경)
- ✅ T3-4 진행률 바 전환, 추가·삭제 페이드, 완료 슬라이드 애니메이션
- ✅ T3-5 대시보드 실시간 갱신 (애니메이션을 기다리지 않고 즉시)

### Phase 4 — 다크 모드·추가 기능
- ✅ T4-1 다크/라이트 토글 스위치 (#1A1A1A / #2D2D2D / #E0E0E0), 저장, 부드러운 전환
- ✅ T4-2 페이지를 열 때 테마 깜빡임 방지 (`<head>` 인라인 스크립트)
- ✅ T4-3 완료 항목 모두 삭제 + 확인 창
- ✅ T4-4 실시간 검색 (+ 일치 부분 강조)
- ✅ T4-5 남은 할 일 배지, 빈 상태 메시지 ("할 일이 없습니다. 추가해보세요!")
- ✅ T4-6 단축키 Alt+N / Alt+1~4 / Alt+D (`e.code` 기준, 한글 자판 대응)
- ✅ T4-7 모바일(≤480px) 최적화, 터치 영역 44px

### Phase 5 — 최종 완성·사용성
- ✅ T5-1 JSON 내보내기 / 파일 가져오기 / 가져오기 전 백업 확인
- ✅ T5-2 정렬: 완료 상태순·생성일순·카테고리순 + 정렬 상태 저장
- ✅ T5-3 드래그 앤 드롭 직접 정렬 (Pointer Events, 터치·키보드 지원)
- ✅ T5-4 성능: 키 기반 DOM 재사용, 검색·저장 디바운싱
- ✅ T5-5 접근성: ARIA 레이블, 포커스 관리, 스크린 리더 알림
- ✅ T5-6 중복 할 일 경고, 삭제 되돌리기(실행 취소 / Ctrl+Z)
- ✅ T5-7 오늘의 격언, 완료율별 응원 메시지
- ✅ T5-8 오류 처리: 저장소 불가·용량 초과·손상 데이터·가져오기 검증
- ✅ T5-9 코드 상세 주석 (16개 섹션 구조)

### Phase 6 — 키워드 자동 분류
- ✅ T6-1 키워드 점수 기반 분류 (`scoreCategories` / `classifyText`), 동점이면 판단 안 함
- ✅ T6-2 입력 중 자동 선택 + 근거 표시, 직접 고르면 자동 분류 중지
- ✅ T6-3 카테고리 없는 예전 데이터·가져오기 파일 자동 분류
- ✅ T6-4 키워드 설정 창: 추가·삭제(되돌리기)·분류 테스트·기본값 복원
- ✅ T6-5 키워드 검증: 빈 값, 30자 제한, 같은·다른 카테고리 중복 차단, 한 글자 경고
- ✅ T6-6 `todoKeywords` 저장, 탭 간 동기화
- ✅ T6-7 안내 문구 속 "키워드 설정 / 키워드 추가하기" 바로가기

### Phase 7 — 데스크톱 레이아웃·통합
- ✅ T7-1 `web_version/` 3단 데스크톱 레이아웃 제작 (사이드바 / 목록 / 진행 현황)

- ✅ T7-3 루트 `index.html`을 반응형 레이아웃으로 교체 (이전 버전은 `mobile_backup/`에 백업)
- ✅ T7-4 `desktop.css`를 `style.css`에 병합, `web_version/` 삭제 → 3파일 단일 앱

### Phase 8 — 데스크톱 점검·수정
- ✅ T8-1 데스크톱 최적화 분석 (창 너비 1024~2560px 측정)

## 3. 개발 중 발견·수정한 버그

| ID | 증상 | 원인 | 조치 |
|---|---|---|---|
| B-01 | 카테고리 없는 예전 데이터를 불러오면 앱이 멈춤 | 키워드 색인이 `loadTodos()` 이후에 정의됨 (TDZ) | 키워드 준비를 상태 초기화보다 앞으로 이동 |
| B-02 | 가져오기 알림의 "실행 취소"가 다른 작업을 되돌릴 수 있음 | 스택 맨 위 항목을 되돌림 | 자기 작업 항목을 직접 참조 |
| B-03 | 키워드 설정 창을 닫은 뒤 포커스가 본문(`<body>`)으로 빠짐 | 연 요소가 다시 그려져 사라졌거나, 클릭해도 버튼에 포커스가 가지 않음(Safari) | 연 요소가 없거나 `<body>`면 입력창으로 |
| B-04 | 설정 창 닫힘 후 정리 작업이 늦게 실행됨 | `<dialog>` `close` 이벤트가 비동기 | 닫을 때 바로 정리, 중복 실행 방지 플래그 |
| B-05 | 1024px 창에서 1단 모바일 화면이 나옴 | 실제 화면 폭이 1000px로 기준(1024px) 미만 | 기준 960px |
| B-06 | 위로 드래그하면 항목이 고정 영역 뒤로 숨은 뒤에야 스크롤 | 자동 스크롤 기준이 화면 맨 위 60px | 고정 영역 아래 끝 + 60px |
| B-07 | 위로 드래그하는데 화면이 아래로 내려감 | 순서 변경 시 브라우저 스크롤 앵커링 보정 | 드래그 중 `overflow-anchor: none` |
| B-08 | Tab 이동 시 항목이 고정 영역에 가려짐 | `scroll-padding-top: auto` | 측정한 높이로 지정 |
| B-09 | 960~1024px에서 사이드바 버튼 글자가 두 줄로 꺾임 | 사이드바 폭 200px | 버튼 이름 축약, 여백 축소, `nowrap` |
