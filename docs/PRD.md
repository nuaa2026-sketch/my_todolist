## 1. 개요

**My Tasks**는 설치나 서버 없이 브라우저에서 `index.html`을 열어 바로 쓰는 개인용 할 일 관리 앱이다.
할 일을 업무·개인·공부 세 카테고리로 나누어 관리하고, 진행률 대시보드로 오늘의 성과를 한눈에 보여 준다.
데이터는 브라우저(localStorage)에 저장되며, 하나의 반응형 페이지가 PC 전체 화면과 휴대폰 화면 모두에 맞춰 바뀐다.

### 1.1 배경
- 처음에는 최대 600px 카드 형태의 모바일 중심 화면으로 만들었다.
- PC 브라우저에서 화면 가운데에 좁은 카드만 보여 공간 활용이 떨어진다는 피드백을 받았다.
- 그래서 데스크톱 전체 화면 레이아웃을 따로 만들었다가, 최종적으로 **하나의 반응형 앱으로 통합**했다.

### 1.2 목표
1. 할 일을 빠르게 추가·완료·수정·삭제할 수 있다.
2. 카테고리 분류를 자동화해 입력 부담을 줄인다(키워드 기반 자동 분류).
3. 진행률과 응원 메시지로 동기를 부여한다.
4. PC·노트북·태블릿·휴대폰 어디서든 화면 크기에 맞는 레이아웃을 제공한다.
5. 키보드만으로도 모든 기능을 쓸 수 있고, 스크린 리더로도 사용할 수 있다.

### 1.3 비목표 (이번 범위 아님)
- 회원가입·로그인, 서버 저장, 여러 기기 간 동기화
- 마감일·알림·반복 일정
- 사용자 정의 카테고리 (카테고리는 3개로 고정)
- 여러 사람이 함께 쓰는 공유 목록

| 사용자 | 특징 | 주요 사용 환경 |

| 모바일 사용자 | 이동 중 빠르게 확인·체크 | 휴대폰 브라우저 (터치) |

## 3. 기능 요구사항

> 우선순위: **P0** 필수 / **P1** 중요 / **P2** 있으면 좋음. 모든 항목은 v1.0에 구현되었다.

### 3.1 할 일 기본 관리

| ID | 요구사항 | 우선순위 | 완료 기준 |
|---|---|---|---|
| FR-01 | 할 일 추가 | P0 | 입력창에서 **Enter** 또는 **추가 버튼**으로 추가된다. 공백만 입력하면 추가되지 않고 입력창이 흔들리며 안내가 표시된다. 최대 200자. |
| FR-02 | 할 일 삭제 | P0 | 각 항목의 × 버튼으로 삭제된다. 삭제 후 알림의 **실행 취소**나 **Ctrl+Z**로 원래 자리에 복구된다. |
| FR-03 | 완료/미완료 토글 | P0 | 체크박스로 토글되며, 완료 항목은 취소선과 흐린 스타일로 표시된다. |
| FR-04 | 자동 저장 | P0 | 추가·삭제·완료·수정·순서 변경 시 자동 저장되고, 새로고침 후에도 유지된다. |
| FR-05 | 인라인 수정 | P1 | 텍스트 **더블클릭**·✎ 버튼·**F2**로 수정 모드에 들어간다. **Enter** 저장, **Esc** 취소. 수정 중 카테고리도 바꿀 수 있다. 빈 내용으로 저장하면 이전 내용을 유지한다. |
| FR-06 | 중복 확인 | P1 | 같은 내용(대소문자·공백 차이 무시)의 할 일을 추가하려 하면 확인 창을 띄운다. 수정 시 중복이면 경고만 표시한다. |
| FR-07 | 완료 항목 일괄 삭제 | P1 | "완료 항목 삭제 (n)" 버튼, 확인 창 필수, 실행 취소 가능. 완료 항목이 없으면 버튼이 비활성화된다. |
| FR-08 | 되돌리기 | P1 | 최근 20개 작업(삭제·일괄 삭제·가져오기)을 되돌릴 수 있다. 입력창 밖에서 Ctrl+Z가 동작한다. |

### 3.2 카테고리

| ID | 요구사항 | 우선순위 | 완료 기준 |
|---|---|---|---|
| FR-10 | 3개 카테고리 | P0 | 업무(work, #4A90E2), 개인(personal, #27AE60), 공부(study, #8E44AD) |
| FR-11 | 카테고리 선택 | P0 | 추가 시 드롭다운으로 선택. 각 항목에 색상 태그와 왼쪽 색상 테두리를 표시한다. |
| FR-12 | 카테고리 필터 | P0 | 전체/업무/개인/공부 필터. 선택된 필터는 강조되고, 필터마다 남은 할 일 수를 표시한다. 마지막 필터를 기억한다. |
| FR-13 | 키워드 자동 분류 | P1 | 입력 중 키워드를 감지해 카테고리를 자동 선택하고 근거를 표시한다(예: "자동 분류 공부 · '토익' 키워드"). 사용자가 직접 고르면 자동 분류를 멈춘다. 동점이면 판단하지 않는다. |
| FR-14 | 키워드 설정 창 | P1 | 카테고리별 키워드 추가·삭제(삭제 되돌리기), 분류 테스트, 기본값 복원. 다른 카테고리와 중복되는 키워드는 막고, 한 글자 키워드는 경고한다. 변경은 즉시 저장·반영된다. |

### 3.7 키보드 단축키

| 단축키 | 동작 |
|---|---|
| `Alt+N` | 새 할 일 입력창으로 이동 |
| `Alt+1` ~ `Alt+4` | 필터: 전체 / 업무 / 개인 / 공부 |
| `Alt+D` | 다크 모드 전환 |
| `/` | 검색창으로 이동 |
| `Ctrl+Z` | 마지막 삭제·가져오기 되돌리기 (입력창 밖에서) |
| `Alt+↑` / `Alt+↓` | 선택한 항목 순서 이동 (직접 정렬) |
| `F2`, 더블클릭 | 수정 시작 (`Enter` 저장, `Esc` 취소) |

한글 자판 상태에서도 단축키가 동작해야 한다(물리 키 기준).

## 4. 비기능 요구사항

| ID | 분류 | 요구사항 |
|---|---|---|
| NFR-01 | 성능 | 할 일 100개 이상에서도 부드럽게 동작한다. 바뀐 항목만 다시 그리고, 검색(200ms)과 저장(300ms)에 디바운싱을 적용한다. |

│ 정렬 [▾]    │                              │ 공부 ███ 1/1 │

### 5.2 모바일·태블릿 (960px 미만)
제목·배지 → 격언 → 진행률 → 검색·테마 → 필터 → 정렬 → 입력 → 목록 → 하단 버튼 순서의 1단 카드 화면.
480px 이하에서는 카드 여백을 없애 화면 전체를 쓰고, 필터를 가로 스크롤로 바꾸며, 설정 창을 아래에서 올라오는 시트 형태로 연다.

## 6. 데이터 요구사항

각 할 일은 다음 구조로 저장한다.

```json
{
  "id": "string (UUID)",
  "text": "string (1~200자)",
  "completed": false,
  "createdAt": "ISO 8601 문자열",
  "category": "work | personal | study"
}
```

- 필터, 정렬, 테마, 사용자 키워드도 저장해 다음 방문 때 그대로 복원한다.
- 카테고리가 없는 예전 데이터는 불러올 때 키워드로 자동 분류한다.
