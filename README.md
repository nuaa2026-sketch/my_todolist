# My Tasks

설치 없이 브라우저에서 바로 쓰는 반응형 할 일 관리 앱입니다.
PC에서는 3단 전체 화면, 휴대폰에서는 1단 카드 화면으로 자동 전환됩니다.

## 주요 기능
- 할 일 추가·완료·인라인 수정·삭제, 실행 취소(Ctrl+Z)
- 업무 / 개인 / 공부 카테고리, 필터, **키워드 기반 자동 분류**와 키워드 설정 창
- 진행률 대시보드, 오늘의 격언, 완료율별 응원 메시지
- 실시간 검색, 정렬(완료 상태·생성일·카테고리·드래그 직접 정렬)
- 다크 모드, 키보드 단축키(Alt+N, Alt+1~4, Alt+D, /)
- JSON 내보내기 / 가져오기
- 데이터는 브라우저 localStorage에만 저장되며 서버로 전송되지 않습니다.

## 실행
`index.html`을 브라우저로 열면 됩니다. 빌드나 설치가 필요 없습니다.
